📌 About

User-Agent Collection is a text-based collection of User-Agent (UA) strings from different browsers, operating systems, and mobile devices.

This repository provides a convenient reference for developers, testers, and researchers who need User-Agent strings for browser compatibility testing, HTTP client configuration, and educational purposes.

✨ Collection Includes

- 📱 Android User-Agent Strings
- 💻 Windows User-Agent Strings
- 🐧 Linux User-Agent Strings
- 🍎 macOS User-Agent Strings
- 🌐 Firefox Browser User-Agents
- 🔍 Legacy Browser User-Agents
- 📦 Various Device and Browser Identifiers

💻 Usage

You can download the collection directly:

curl -L https://raw.githubusercontent.com/Pro-Max-420/ua/main/bbnew.txt -o bbnew.txt

Or use Python to read the collection:

with open("bbnew.txt", "r", encoding="utf-8") as file:
    user_agents = [
        line.strip()
        for line in file
        if line.strip()
    ]

print(f"Total User-Agents: {len(user_agents)}")

⚠️ Disclaimer

- User-Agent strings are provided for educational, development, and compatibility-testing purposes.
- User-Agent strings can be modified or spoofed by clients.
- A User-Agent string does not verify the actual device, browser, or operating system.
- This collection should not be used as an authentication or security mechanism.
